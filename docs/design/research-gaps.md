# Research gaps

Scanned: Q1–Q96, decisions 0001–0007, the design audit and `docs/research/feature-inventory.md`. Updated: 2026-10-01.

**What this page contains.** Every design decision that holds only if a fact about an outside system is true (Stripe, Razorpay, Google, Python and SQLite behaviour, hosting, licences, the market), whether that fact is already sourced, and how to settle it if not.

**How to read it.** Rows that would break the architecture come first, then rows by the earliest build step that depends on them ([build-order.md](build-order.md): P0-P6, then "after pitching"). **Check** is `OK` with its source, `RESEARCH` when documentation can settle it, or `SPIKE` when only running code against the real system can. Most SPIKE rows belong in the recording spike ([testing.md](testing.md)).
