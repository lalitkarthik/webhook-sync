# Third-party notices

Parts of webhook-sync were ported from four open-source projects. The originals are in Python, Go, TypeScript and Rust; the code here is Python, rewritten from them and changed as each row says. This file names every such file, where it came from, its licence and its copyright line, and then gives the licence texts. Only MIT and Apache-2.0 code was used ([ADR 0005](docs/design/decisions/0005-permissive-licences-only.md)).

The commit beside each project is the one that was read. None of the four has a NOTICE file.

| Our file | Ported from | Licence and copyright | Main changes |
|---|---|---|---|
| `src/webhook_sync/receiver/app.py`, `src/webhook_sync/receiver/store.py`, `src/webhook_sync/receiver/checks.py` | [hookline](https://github.com/hassanatic/hookline) at c0e549e: `hookline/app.py`, `hookline/store.py` | MIT. Copyright (c) 2026 Hassan Abdullah | The dedupe key is per source, and for Razorpay it is the `x-razorpay-event-id` header. The key columns are `NOT NULL`. A known event id with a different fingerprint is a conflict. Every path ends its transaction. An empty secret refuses to start. Bad input gets a 400 and never a 500. A security header sent twice is rejected. |
| `src/webhook_sync/queue/operations.py`, `src/webhook_sync/queue/runner.py` | [driftless](https://github.com/quyumkehinde/driftless) at e49725d: `internal/store/queries/jobs.sql`, `internal/queue/queue.go` | Apache-2.0. Copyright 2026 Quyum Kehinde | Rewritten from Go on Postgres to Python on SQLite. One live job per payment with a rerun flag. Claim tokens and heartbeats. Three error classes. A reaper that returns expired jobs one row at a time, with backoff. |
| `src/webhook_sync/sweeper/sweep.py` | driftless at e49725d: `internal/sweep/sweeper.go` | Apache-2.0. Copyright 2026 Quyum Kehinde | Time slices on the source's own clock. An empty slice moves the checkpoint. Razorpay's payments and refunds are listed by creation date, because Razorpay has no list of events. |
| `src/webhook_sync/sinks/sheets.py` | [sync-engine](https://github.com/stripe/sync-engine) at 0cb8ca4: `packages/destination-google-sheets/src/writer.ts` | Apache-2.0. Copyright 2025 Supabase | Rewritten from TypeScript. A failed read stops the flush. Tabs are read by sheet id. Typed `updateCells` replaces `pasteData`. Key cells are written only on append. A check reads the keys back after each write. There is no version guard on the sheet's side. |
| `src/webhook_sync/queue/retry.py` | [svix-webhooks](https://github.com/svix/svix-webhooks) at cb056ba: the retry schedule in `server/svix-server/config.default.toml` and `server/svix-server/src/worker.rs` | MIT. Copyright (c) 2021 Svix (https://www.svix.com) | Only the idea of a fixed table of waits was taken. There are two profiles, each wait is multiplied by a random factor between 0.5 and 1.5, and a `Retry-After` is never shortened. |
